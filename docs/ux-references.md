# 검색 편의 기능 참고 기록

확인일: 2026-10-15 (KST). 기존 밝은 테마, 다중 실험체 필터, 최대 7개 구간의 가중 평균 순위 표시는 유지한다.

## 확인한 공개 자료

| 자료 | 직접 확인한 내용 | 이 앱에 적용하는 방식 |

위 자료는 공개 프로젝트 작성자가 설명한 기능이다. 운영 중인 서비스의 현재 기능 목록을 확인한 것으로 해석하지 않는다. DAK.GG와 OP.GG 페이지에 대한 직접 연결은 이 환경의 프록시·도메인 정책에서 차단되었다(`Tunnel connection failed: 403 Forbidden`). 접근 정책은 변경하지 않았다.

## 현재 앱에 맞춘 변경

- 최근 조회와 별개로 자주 쓰는 검색 조건을 최대 5개 저장한다. 닉네임, 날짜, 모드, 실험체만 이 브라우저에 보관한다. 다른 기기와 동기화하지 않는다. 불러온 조건을 분석할 때는 첫 페이지부터 조회하며, 페이지 크기는 현재 설정을 사용한다.
- 저장한 조건을 불러오면 입력란만 바뀐다. 실제 조회는 사용자가 분석 버튼을 눌렀을 때 수행한다. 개별 삭제와 전체 비우기를 제공한다.
- 최근 7·30·90일을 한국 시간의 오늘을 포함한 날짜 범위로 채운다. 직접 날짜 입력도 유지한다. 이는 이 프로젝트의 날짜 범위 요구에 맞춘 추가 설계다.
- 결과의 링크 복사는 마지막 성공한 조회 조건을 사용한다. 아직 적용하지 않은 입력값이 기존 결과의 링크에 섞이지 않게 한다. 클립보드를 사용할 수 없으면 직접 복사할 수 있는 링크를 표시한다.
- 입력 조건과 표시 중인 결과가 달라졌을 때 안내한다. 잘못된 날짜 등은 서버 요청 전에 검증한다.

외부 프로젝트의 코드·이미지·브랜드 자산이나 새 의존성을 가져오지 않는다. 공식 API 어댑터 및 API 오류 분류는 변경하지 않는다. 실제 계정 조회와 제공사 점검 종료 확인은 이번 UI 검증에 포함하지 않는다.
