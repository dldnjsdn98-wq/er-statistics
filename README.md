# ER Insight

이터널 리턴 전적을 한국 시간 날짜 범위, 게임 모드, 여러 실험체로 조회하는 한국어 대시보드입니다. 처음 실행하면 **실제 계정 전적이 아닌 데모 데이터**가 표시됩니다. 날짜·모드·실험체 조건은 함께 적용되고, 선택한 실험체끼리는 OR 조건입니다.

## 실행

Node.js 20 이상이 필요합니다. Node.js 24에서 검증했습니다.

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 데모를 볼 수 있습니다. API 키와 데이터베이스가 없어도 동작합니다. 데모 닉네임은 `데모플레이어`이며, 다른 닉네임을 입력해도 샘플 프로필로 응답하고 화면에 출처를 표시합니다. 최근 약 83일 사이의 고정 규칙 샘플입니다. 서버가 실행되는 현재 한국 날짜를 기준으로 생성되며 새로고침 때 무작위로 바뀌지 않습니다.

## 실제 API 연결

`.env.example`을 참고해 `.env.local`에 다음 값을 설정하고 서버를 재시작하세요. `ER_DATA_SOURCE`는 앞뒤 공백과 대소문자를 무시하므로 `LIVE`도 실제 API 모드로 동작합니다.

```dotenv
ER_DATA_SOURCE=live
ER_API_KEY=발급받은_서버용_키
# 공식 startDtm에 시간대 정보가 없는 경우에만 필요
ER_API_TIME_ZONE=Asia/Seoul
```

키는 서버의 `x-api-key` 헤더에만 사용됩니다. `NEXT_PUBLIC_` 변수로 설정하지 마세요. 공식 API 주소는 `https://open-api.bser.io`로 고정되어 있습니다. 실패 시 데모로 자동 전환하지 않고 명시적인 오류를 표시합니다. 현재 실행 환경에서는 공식 API 키와 API 호스트 접근이 연결되지 않아 실제 인증·응답 형태·처리량은 검증하지 못했습니다. 다른 Codex 프로젝트에 등록된 키가 이 앱의 실행 환경에도 연결되어야 합니다.

라이브 모드는 닉네임을 UID로 조회한 뒤 `/v1/user/games/uid/{uid}`의 문서화된 응답을 수집합니다. 공식 API의 페이지네이션과 전체 완료 조건이 확인되지 않았기 때문에 라이브 결과는 **일부일 수 있음**으로 표시합니다. 최근 90일보다 오래된 전적은 앱이 이전에 수집해 저장한 기록만 볼 수 있습니다. 닉네임 변경으로 UID가 바뀌면 변경 전 전적은 합치지 않습니다. RP/MMR은 일부 키에만 제공되므로 집계하지 않습니다.

공식 `startDtm`에 `Z`나 `+09:00` 같은 오프셋이 있으면 해당 값을 사용합니다. 오프셋이 없다면 `ER_API_TIME_ZONE`을 `Asia/Seoul` 또는 `UTC`로 지정해야 합니다. 미설정 상태에서 시간대 없는 시각이 오면 조회가 실패합니다. 모든 사용자 날짜 범위는 한국 시간 자정 기준이며 종료일을 포함합니다.

## PostgreSQL 저장 (선택)

라이브 모드에서 `DATABASE_URL`을 설정하기 전에 [db/001_init.sql](db/001_init.sql)을 데이터베이스에 적용하세요.

```bash
psql "$DATABASE_URL" -f db/001_init.sql
```

`DATABASE_URL`이 없으면 라이브 결과는 프로세스 메모리에 보관되고 재시작 시 사라집니다. API 응답은 이 상태를 표시합니다. DB 연결이 실패하면 메모리로 조용히 전환하지 않고 `STORAGE_UNAVAILABLE` 오류를 반환합니다. 이미 저장된 실제 전적이 있을 때 일시적인 공식 API 실패가 발생하면 출처는 계속 `live`로 두고 마지막 수집 시각과 `stale` 경고를 표시합니다. 데모 데이터는 PostgreSQL에 저장하지 않습니다.

## 내부 API

- `GET /api/characters`: 다중 선택용 실험체 목록. 실험체 메타데이터가 없어도 알고 있는 코드를 직접 입력할 수 있습니다.
- `GET /api/stats?nickname=데모플레이어&startDate=2026-10-01&endDate=2026-10-15&characterCodes=1,2&mode=all&page=1&pageSize=20`: 필터된 요약, 실험체별 집계, 최근 게임 페이지, 수집 범위를 반환합니다. `characterCodes` 생략 시 모든 실험체를 대상으로 합니다.

선택한 실험체의 경기가 0건이어도 개별 행이 표시됩니다. 기록이 없는 평균·승률은 `null`이며 UI에는 `—`로 표시됩니다. 유효하지 않은 날짜·모드·실험체 코드는 HTTP 400입니다. [API 계약](docs/api-contract.md)에 모든 응답 필드와 오류 코드가 있습니다.

## 검증

```bash
npm test
npm run typecheck
npm run build
```

테스트는 한국 시간 날짜 경계, 다중 실험체 OR와 기간·모드 AND, 중복 게임, 0경기 행, 결측 수치, 페이지 구분, API 응답 정규화와 오류를 검증합니다. PostgreSQL 통합과 실제 공식 API 호출은 별도 연결 환경에서 확인해야 합니다. [설계](docs/architecture.md)와 [연결 체크 목록](docs/acceptance.md)을 참고하세요.
